## 1\. 제품 개요

* **제품명**: 킹받는 AI 관상소 (가칭)
* **목표**: 사용자가 올린 얼굴 사진 한 장을 바탕으로 Google Gemini AI가 현학적인 B급 병맛 별명과 촌철살인 관상평을 생성해 주는 초경량 오락용 웹앱
* **핵심 가치**: 무설치 / 무로그인 / 사진 비저장 / 운영비 0원 / 10초 이내 스낵 콘텐츠
* **운영 성격**: 순수 재미용 개인 프로젝트. 고도화·수익화 계획 없음.
* **디자인 콘셉트**: "동네 용한 점집 간판을 패러디한 B급 밈" — 오방색·한지·부적·붓글씨. 색상·글꼴·버튼 등 시각 기준은 `03\_UI\_FLOW.md` 4장에서만 정의.

## 2\. 기능 요구사항 (Features)

### 2.1 핵심 기능 (MVP - 필수)

* \[ ] **F-1. 사진 입력 (촬영 및 업로드)**

  * 모바일 환경: 카메라 즉석 촬영 (`capture` 속성) 지원
  * 앨범/PC 환경: 갤러리 파일 선택 및 드래그 앤 드롭 지원
  * 업로드 전 프리뷰(미리보기) 제공
  * 전송 전 브라우저에서 이미지 축소·JPEG 변환 (상세: 3.2)
* \[ ] **F-2. Gemini Vision AI 관상 분석 엔진**

  * 경량 서버(API 프록시)를 거쳐 Google Gemini Multimodal API로 사진 분석 (상세: 3.5)
  * 현학적 B급 병맛 페르소나와 톤 기준(3.4)이 적용된 프롬프트 설계
  * 정형화된 결과 포맷(JSON 형식 응답) 파싱:

    * `nickname`: 대표 캐릭터 호칭/별명 (예: "야근에 영혼 팔린 방구석 전략가")
    * `summary`: 전체 관상 한줄평
    * `features`: 부위별 관상평 (이마, 눈/눈빛, 코/재물운, 입술/말실수운 등)
    * `luckyItem`: 뜬금없는 킹받는 행운의 아이템 (예: "다 식은 믹스커피")
* \[ ] **F-3. 킹받는 인터랙티브 로딩**

  * AI 분석 대기 시간 동안 지루하지 않게 롤링되는 현학적·유머러스한 로딩 멘트
  * (예: "『마의상법』 제3권 미간편 대조 중...", "눈빛 속 숨겨진 흑염룡의 기운 판독 중...", "조선 팔도 관상가 협회에 자문 요청 중...")
  * 점집 분위기 연출(방울, 촛불빛, 오방색 링) 포함 — 상세는 `03\_UI\_FLOW.md` 4.5
* \[ ] **F-4. 결과 화면 및 다시하기**

  * 분석된 사진 썸네일과 캐릭터 칭호, 부위별 관상평 표시
  * 결과 화면 하단에 면책 문구 표시: "본 결과는 AI가 지어낸 재미용 허구입니다."
  * **스크린샷 친화 레이아웃**: 모바일 한 화면 안에 핵심 결과(칭호·한줄평·부위별 평)가 들어오도록 구성
  * 결과는 **부적 종이 모양 카드**로 표시 — 상세는 `03\_UI\_FLOW.md` 3.3, 4장
  * `\[다시 검사하기]` 버튼 클릭 시 메인으로 초기화
* \[ ] **F-5. 공유 (텍스트 + 이미지)**

  * **텍스트 공유**: 결과 텍스트(칭호, 한줄평, 행운의 아이템)를 웹 브라우저 네이티브 공유 (`navigator.share`)로 전송 (카카오톡, 메시지 등). 공유 텍스트 끝에 서비스 주소를 붙여 친구도 해볼 수 있게 함.
  * 네이티브 공유를 지원하지 않는 환경(주로 PC)에서는 같은 텍스트를 클립보드에 복사
  * **결과 이미지 저장**: 결과 화면을 이미지(PNG)로 저장하는 버튼 제공. 이미지는 **브라우저 안에서만 생성**하고 서버로 보내지 않음.
  * 결과별 고유 링크는 만들지 않음 (Zero-DB이므로 저장할 곳이 없음)

## 3\. 정책 및 규칙 (Business Rules)

### 3.1 개인정보 및 데이터 정책 (Zero-DB)

* 사용자가 업로드한 이미지와 분석 결과는 우리 서버의 디스크나 데이터베이스에 절대 저장하지 않음.
* 서버는 이미지를 메모리에서 Gemini API로 전달만 하고, 응답을 돌려준 뒤 폐기함.
* **Gemini 무료 티어 관련 정직한 고지**: Google 약관상 무료 티어로 보낸 데이터는 Google의 서비스 개선에 쓰일 수 있음. 따라서 "즉시 파기됩니다"처럼 단정하지 않고, 메인 화면에 아래 취지로 고지함.

  * "사진은 저희 서버에 저장되지 않아요. 다만 분석을 위해 Google Gemini로 전송되며, Google의 정책에 따라 처리될 수 있어요."
* 구현 전에 Gemini API 약관 원문을 다시 확인하고, 고지 문구를 최종 확정함.

### 3.2 이미지 입력 유효성 및 예외 처리

* **지원 형식**: jpg, jpeg, png, webp
* **HEIC (아이폰 사진)**: 별도 변환 라이브러리를 쓰지 않음.

  * 아이폰 Safari는 사진을 고를 때 보통 자동으로 JPEG로 바꿔서 넘겨줌.
  * 브라우저가 이미지를 읽지 못하면 안내 메시지 출력: "이 사진은 너무 고귀한 포맷이라 소인이 읽지 못하옵니다. 카메라로 바로 찍어 주시옵소서!"
* **원본 용량 제한**: 10MB 이하
* **전송 전 자동 축소**: 브라우저에서 긴 변 기준 약 1024px, JPEG로 변환 후 전송 (무료 호스팅의 요청 크기 제한 대응 + 속도 향상)
* **얼굴 미인식 예외**: AI가 얼굴을 인식하지 못할 경우(풍경, 동물, 사물 등), 재치 있는 에러 메시지 출력 ("이것은 사람이 아니거나 외계인입니다. 정면 얼굴을 다시 찍어주세요!")
* **분석 실패/시간 초과**: "관상신(神)께서 잠시 자리를 비우셨습니다. 잠시 후 다시 시도해 주세요."
* **무료 사용량 초과 시**: 유료로 넘어가지 않고 요청을 막은 뒤 안내 출력: "오늘 관상소 기운이 모두 소진되었습니다. 내일 다시 찾아주시오."

### 3.3 이용 대상 및 사진 정책

* **만 18세 이상만 이용**: 메인 화면에 "만 18세 이상 이용 가능" 표시. (Gemini API 약관상 만 18세 미만 대상 서비스 사용 제한. 구현 전 약관 원문 재확인)
* **본인 또는 동의받은 사진만**: 업로드 영역에 "본인 사진 또는 당사자에게 허락받은 사진만 올려주세요" 안내.
* **면책 고지**: 메인과 결과 화면에 "본 결과는 AI가 지어낸 재미용 허구이며, 실제 성격·운세와 무관합니다" 표시.

### 3.4 톤 및 콘텐츠 기준 (프롬프트 가이드)

* **톤**: 현학적 + B급 병맛. 고문헌·관상학 용어를 그럴듯하게 흉내 내면서 현대 밈과 섞음.

  * 예: "천정(天庭)이 넓으니 이는 『마의상법』에 이르길 '회의 시간에 딴생각하는 자의 상'이라."
* **평가 대상**: 얼굴은 '운세와 상황 밈'으로만 풀이함. 외모 자체(잘생김·못생김, 체형, 피부, 나이, 인종, 성별 등)는 평가하지 않음.

  * ⭕ "콧대에 재물운이 깃들었으나, 배달앱 장바구니에서 모두 새어 나가는 상"
  * ❌ "코가 커서 웃기게 생김", "살이 쪄 보임"
* **금지**: 외모 비하, 혐오·차별 표현, 정치·종교, 성적 표현, 실제 인물(연예인 등) 닮은꼴 단정
* **결과는 항상 유쾌하게 마무리**: 팩폭을 하더라도 마지막은 웃으며 넘길 수 있는 덕담이나 반전으로 끝냄.
* **무속 콘셉트 사용 원칙**: 무속·점집은 패러디 소재로만 사용. 실제 무속 신앙 비하, 저주·액운 협박("이대로면 큰일 난다" 류), 귀신·공포 표현은 쓰지 않음. 시각 요소 기준은 `03\_UI\_FLOW.md` 4.6.

### 3.5 API 구조 및 비용 정책 (0원 운영)

* **구조**: 브라우저 → 우리 경량 서버(서버리스 함수) → Gemini API

  * API 키는 서버에만 보관하여 브라우저에 노출하지 않음.
* **비용 0원 원칙**:

  * Gemini는 **무료 티어만** 사용하고, Google 프로젝트에 **결제 수단(Billing)을 연결하지 않음**. 결제 수단이 없으면 사용량이 한도를 넘어도 요금이 나가지 않고 요청이 거절됨.
  * 글꼴은 Google Fonts 무료 글꼴만 사용 (`03\_UI\_FLOW.md` 4.3)
  * 호스팅도 무료 플랜만 사용 (예: Vercel Hobby. 비상업용 무료 플랜이며 본 프로젝트는 수익화 계획이 없어 조건에 맞음). 구체적인 선택은 `04\_DEV\_PLAN.md`에서 확정.
  * 사용 모델은 개발 시점에 무료 티어로 제공되는 Gemini 멀티모달 모델 중에서 선택 (`04\_DEV\_PLAN.md`에서 확정).

## 4\. 화면 범위 (화면 5개 이하)

1. **Screen 1**: 메인 \& 업로드 화면 (랜딩 + 촬영/업로드 + 18세 이상·사진 동의·개인정보 고지)
2. **Screen 2**: 분석 로딩 화면 (현학적 킹받는 멘트 롤링)
3. **Screen 3**: 관상 결과 \& 공유 화면 (캐릭터 호칭 + 부위별 평 + 텍스트 공유 + 이미지 저장 + 면책 문구)

## 5\. 성공 지표 (재미용 개인 프로젝트 기준)

> 방문자 분석 도구 없이 직접 확인할 수 있는 지표만 사용합니다.

* **운영비 0원 유지**: 배포 후 Gemini와 호스팅 청구 금액 0원
* **응답 속도**: 사진 업로드부터 결과 표시까지 10초 이내
* **분석 성공률**: 정면 얼굴 사진 10장 테스트 시 9장 이상 정상 결과 출력
* **톤 기준 준수**: 테스트 결과 10건 중 외모 비하 표현 0건
* **지인 반응**: 지인 5명 이상이 써보고 결과를 공유(텍스트 또는 이미지)함
