이 문서는 아이디어를 바탕으로 실제 구현할 기능과 정책, 범위를 명확히 정의하는 문서입니다.

> **상태: 승인 (2026-11-03)**
> 최종 수정: 2026-11-06 — DB 정책 변경 (Zero-DB → 이미지 비저장 + 방명록), F-6 방명록 기능 추가

---

## 1. 제품 개요

- **제품명**: 킹받는 AI 관상소
- **목표**: 사용자가 올린 얼굴 사진 한 장을 바탕으로 Google Gemini AI가 현학적인 B급 병맛 별명과 촌철살인 관상평을 생성해 주는 초경량 오락용 웹앱
- **핵심 가치**: 무설치 / 무로그인 / 얼굴 사진 비저장 / 운영비 0원 / 10초 이내 스낵 콘텐츠
- **운영 성격**: 순수 재미용 개인 프로젝트. 고도화·수익화 계획 없음.
- **디자인 콘셉트**: "동네 용한 점집 간판을 패러디한 B급 밈" — 오방색·한지·부적·붓글씨. 색상·글꼴·버튼 등 시각 기준은 `03_UI_FLOW.md` 4장에서만 정의.

## 2. 기능 요구사항 (Features)

### 2.1 핵심 기능 (MVP - 필수)

- [x] **F-1. 사진 입력 (촬영 및 업로드)** ✅ 완료
  - 모바일 환경: 카메라 즉석 촬영 (`capture` 속성) 지원
  - 앨범/PC 환경: 갤러리 파일 선택 및 드래그 앤 드롭 지원
  - 업로드 전 프리뷰(미리보기) 제공
  - 전송 전 브라우저에서 이미지 축소·JPEG 변환 (상세: 3.2)

- [x] **F-2. Gemini Vision AI 관상 분석 엔진** ✅ 완료
  - 경량 서버(API 프록시)를 거쳐 Google Gemini Multimodal API로 사진 분석 (상세: 3.5)
  - 현학적 B급 병맛 페르소나와 톤 기준(3.4)이 적용된 프롬프트 설계
  - 정형화된 결과 포맷(JSON 형식 응답) 파싱:
    - `nickname`: 대표 캐릭터 호칭/별명 (예: "야근에 영혼 팔린 방구석 전략가")
    - `summary`: 전체 관상 한줄평
    - `features`: 부위별 관상평 (이마, 눈/눈빛, 코/재물운, 입술/말실수운 등)
    - `luckyItem`: 뜬금없는 킹받는 행운의 아이템 (예: "다 식은 믹스커피")

- [x] **F-3. 킹받는 인터랙티브 로딩** ✅ 완료
  - AI 분석 대기 시간 동안 지루하지 않게 롤링되는 현학적·유머러스한 로딩 멘트
  - 점집 분위기 연출(방울, 촛불빛, 오방색 링) 포함 — 상세는 `03_UI_FLOW.md` 4.5

- [x] **F-4. 결과 화면 및 다시하기** ✅ 완료
  - 분석된 사진 썸네일과 캐릭터 칭호, 부위별 관상평 표시
  - 결과 화면 하단에 면책 문구 표시
  - **스크린샷 친화 레이아웃**: 모바일 한 화면 안에 핵심 결과가 들어오도록 구성
  - 결과는 **부적 종이 모양 카드**로 표시
  - `[다시 검사하기]` 버튼 클릭 시 메인으로 초기화

- [x] **F-5. 공유 (텍스트 + 이미지)** ✅ 완료
  - **텍스트 공유**: 결과 텍스트를 웹 브라우저 네이티브 공유 (`navigator.share`)로 전송. 미지원 환경에서는 클립보드 복사.
  - **결과 이미지 저장**: 결과 화면을 PNG로 저장. 브라우저 안에서만 생성, 서버 전송 없음.

- [x] **F-6. 방명록** ✅ 완료
  - 관상 결과 화면 하단에 "📜 방명록에 남기기" 버튼 제공 (선택 사항)
  - 클릭 시 인라인 폼 표시: 이름(최대 20자) + 한마디(최대 100자) 입력
  - 제출 시 AI 별명(`nickname`)과 행운 아이템(`luckyItem`)이 자동으로 함께 저장
  - 얼굴 사진은 방명록에 저장되지 않음
  - `/guestbook` 페이지에서 방명록 목록 열람 가능 (최신 50건, 30초 ISR 캐시)
  - 관리용 `is_hidden` 필드로 부적절한 항목 숨김 처리 가능

## 3. 정책 및 규칙 (Business Rules)

### 3.1 데이터 저장 정책

**이미지 비저장 (유지):**
- 사용자가 업로드한 얼굴 사진은 우리 서버의 디스크나 데이터베이스에 절대 저장하지 않음.
- 서버는 이미지를 메모리에서 Gemini API로 전달만 하고, 응답을 돌려준 뒤 폐기함.
- **Gemini 무료 티어 고지**: Google 약관상 무료 티어로 보낸 데이터는 Google의 서비스 개선에 쓰일 수 있음. 메인 화면에 아래 취지로 고지:
  - "사진은 저희 서버에 저장되지 않아요. 다만 분석을 위해 Google Gemini로 전송되며, Google의 정책에 따라 처리될 수 있어요."

**방명록 선택 저장:**
- 분석 완료 후 사용자가 직접 "방명록에 남기기"를 선택한 경우에만 텍스트 결과(이름, 한마디, AI 별명, 행운 아이템)를 DB에 저장.
- 얼굴 사진은 방명록에도 저장되지 않음.
- DB: NeonDB (Serverless PostgreSQL) — `guestbook` 테이블 (상세: `04_DEV_PLAN.md`)

**분석 결과 로그:**
- `analyses` 테이블에 분석 결과(닉네임, 요약, 특징, 행운 아이템)를 자동 저장 (non-blocking).
- 사용량 파악 및 디버깅 목적. 얼굴 사진 미포함.

### 3.2 이미지 입력 유효성 및 예외 처리

- **지원 형식**: jpg, jpeg, png, webp
- **HEIC (아이폰 사진)**: 별도 변환 라이브러리를 쓰지 않음. 아이폰 Safari가 자동 JPEG 변환. 실패 시 안내.
- **원본 용량 제한**: 10MB 이하
- **전송 전 자동 축소**: 긴 변 기준 약 1024px, JPEG로 변환 후 전송
- **얼굴 미인식 예외**: 재치 있는 에러 메시지 출력
- **분석 실패/시간 초과**: "관상신(神)께서 잠시 자리를 비우셨습니다."
- **무료 사용량 초과 시**: 요청 차단 후 안내

### 3.3 이용 대상 및 사진 정책

- **만 18세 이상만 이용**: 메인 화면에 표시. (Gemini API 약관 제한)
- **본인 또는 동의받은 사진만**: 업로드 영역에 안내.
- **면책 고지**: 메인과 결과 화면에 표시.

### 3.4 톤 및 콘텐츠 기준 (프롬프트 가이드)

- **톤**: 현학적 + B급 병맛. 고문헌·관상학 용어를 그럴듯하게 흉내 내면서 현대 밈과 섞음.
- **평가 대상**: 얼굴은 '운세와 상황 밈'으로만 풀이. 외모 자체(잘생김·못생김, 체형, 피부, 나이, 인종, 성별 등)는 평가하지 않음.
  - ⭕ "콧대에 재물운이 깃들었으나, 배달앱 장바구니에서 모두 새어 나가는 상"
  - ❌ "코가 커서 웃기게 생김", "살이 쪄 보임"
- **금지**: 외모 비하, 혐오·차별 표현, 정치·종교, 성적 표현, 실제 인물 닮은꼴 단정
- **결과는 항상 유쾌하게 마무리**: 팩폭을 하더라도 마지막은 웃으며 넘길 수 있는 덕담이나 반전으로 끝냄.
- **무속 콘셉트 사용 원칙**: 패러디 소재로만 사용. 실제 무속 비하, 저주·액운 협박, 귀신·공포 표현 금지.

### 3.5 API 구조 및 비용 정책 (0원 운영)

- **구조**: 브라우저 → 서버리스 함수(Next.js API Route) → Gemini API
- **비용 0원 원칙**:
  - Gemini: **무료 티어만** 사용, Google 프로젝트에 **결제 수단 미연결**
  - DB: NeonDB **무료 플랜** (0.5GB, 월 190시간 컴퓨팅)
  - 글꼴: Google Fonts 무료 글꼴만 사용
  - 호스팅: Vercel Hobby 무료 플랜

## 4. 화면 범위

1. **Screen 1**: 메인 & 업로드 화면 (랜딩 + 촬영/업로드 + 고지)
2. **Screen 2**: 분석 로딩 화면 (현학적 킹받는 멘트 롤링)
3. **Screen 3**: 관상 결과 & 공유 화면 (칭호 + 부위별 평 + 공유 + 이미지 저장 + 방명록 폼 + 면책 문구)
4. **Screen 4**: 방명록 목록 페이지 (`/guestbook`) — 최신 50건, ISR 30초

## 5. 성공 지표

> 방문자 분석 도구 없이 직접 확인할 수 있는 지표만 사용합니다.

- **운영비 0원 유지**: 배포 후 Gemini, NeonDB, 호스팅 청구 금액 0원
- **응답 속도**: 사진 업로드부터 결과 표시까지 10초 이내
- **분석 성공률**: 정면 얼굴 사진 10장 테스트 시 9장 이상 정상 결과 출력
- **톤 기준 준수**: 테스트 결과 10건 중 외모 비하 표현 0건
- **지인 반응**: 지인 5명 이상이 써보고 결과를 공유함
